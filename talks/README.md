# 강연·발표 노트북 (talks)

강연·발표에서 시연한 노트북을 모아 둔 폴더입니다. 책의 장(章) 노트북과 달리 **이 폴더의 노트북은 혼자서 실행됩니다.**
저장소 전체를 내려받거나(clone), Google 드라이브를 연결하거나, API 키를 발급받을 필요가 없습니다.

| 주제 | 노트북 | 발표 |
|---|---|---|
| 베버리지 곡선과 미국 노동시장 | [beveridge/](beveridge/) | 신영증권 (2026.10), 한국은행 출입기자 간담회 (2026.11) |

## 폴더 규칙 (관리용)

- **주제별 폴더 하나에 노트북 하나.** 같은 주제를 여러 행사에서 쓰면 노트북은 그대로 두고 행사별 **git 태그**로 그날의 버전을 고정합니다.
  - 태그 이름: `talk-YYYY-MM-행사명` (예: `talk-2026-10-shinyoung`)
  - 강의안·QR에는 태그가 들어간 Colab 링크를 씁니다. 이후 노트북을 고쳐도 그 행사 링크의 내용은 바뀌지 않습니다.
- 노트북 첫 셀에 사용법(로그인 → 런타임 → 모두 실행 → 설정 바꾸기)을 넣고, 설정은 Colab 입력란(`#@param`)으로 만듭니다.
- 인터넷 데이터가 막힐 때를 대비해 스냅샷 CSV를 함께 두고, 그림 출력을 저장한 채로 커밋합니다(실행하지 않아도 GitHub에서 그림이 보이도록).
