# 데이터 파일 준비

교재 실습에 필요한 데이터 파일을 아래 순서대로 준비해 주세요.

---

## Step 1. 데이터 파일 다운로드

아래 두 가지 방법 중 하나를 선택하세요.

**방법 A: ZIP 파일로 다운로드**

1. 이 페이지 상단의 초록색 **[Code]** 버튼을 클릭합니다.
2. **[Download ZIP]** 을 클릭하여 파일을 다운로드합니다.
3. 다운로드된 ZIP 파일의 압축을 해제합니다.

**방법 B: Git으로 클론**

```bash
git clone https://github.com/FinancialEconomicsPython/resources.git
```

---

## Step 2. 구글 드라이브에 업로드

1. [구글 드라이브](https://drive.google.com)에서 본인의 작업 폴더 안에 **`data`** 폴더를 생성합니다.
2. Step 1에서 받은 `data` 폴더 안의 파일을 **모두** 업로드합니다.

```
내 드라이브/
└── Colab Notebooks/
    └── book_FinancialEconomics/
        └── data/   ← 이 폴더에 모든 파일 업로드
